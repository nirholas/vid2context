Each page below collects requests of one kind. Every request is runnable: change the fields, press **Run**, and the response appears under it. Until you run one, each block shows a real response recorded from a vid2context server, and the same request as curl, JavaScript, Python and, where they exist, the CLI command and the MCP tool call.

## Runnable requests

{{pages:examples}}

The **Server** menu on any block picks where requests go: the API on this site, a server on your machine (`http://127.0.0.1:8787`), or any other URL. The [Tutorials overview](/docs/tutorials/#how-the-run-button-works) explains how to start a local server that this page may call.

For step-by-step lessons that use these requests in order, start with [Your first transcript](/docs/tutorials/first-transcript/).
