## Expand a playlist

```run items
```

## A context pack for one video

```run pack
```

## One pack for several videos

```run pack-many
```

## Every format in a zip

```run bundle
```

## Find a topic across videos

```run research
```

## Search saved transcripts

```run search
```

[Many videos at once](/docs/tutorials/many-videos/) walks through these in order.
