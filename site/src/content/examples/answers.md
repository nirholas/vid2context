Each of these runs on the free LLM chain, so they work with no key, and each checks the model's citations against the transcript.

## Ask a question

```run ask
```

## Stream the answer

```run ask-stream
```

## A cited brief

```run brief
```

## Structured data from a template

```run extract-template
```

## Structured data from your own schema

```run extract-schema
```

[Cited answers and briefs](/docs/tutorials/cited-answers/) explains each response.
