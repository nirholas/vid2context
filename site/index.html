Try it

This calls the public HTTP API at /api/v1/transcript. YouTube sometimes blocks requests from cloud servers. If that happens here, run vid2context on your own machine, where it works reliably.

How it works

For every input, vid2context resolves the source and fetches metadata and chapters. It then walks a fallback chain until it has a transcript. Every attempt is recorded, so you can always see what was tried and why it worked or failed.

Free first, paid last

Each speech-to-text and LLM step runs through a chain of rungs, where a rung is one provider, one model and one credential. The chain falls through on errors, rate limits and outages. With zero configuration it already works.

Use it

The same TypeScript core runs behind every surface. You need Node.js 22 or newer.

# install from source
git clone https://github.com/nirholas/vid2context.git
cd vid2context
npm install

# a YouTube link, with timestamps
npm run cli -- "https://www.youtube.com/watch?v=jNQXAC9IVRw" --timestamps

# or a local file, as JSON
npm run cli -- ./interview.mp3 --format json > interview.json

Program output goes to stdout and logs go to stderr, so vid2context URL > transcript.txt stays clean.

# from the repo root
claude mcp add vid2context -- "$PWD/node_modules/.bin/tsx" "$PWD/packages/mcp/src/bin.ts"

Then ask: "get the transcript of https://youtu.be/jNQXAC9IVRw and summarize it with timestamps". The server exposes get_transcript and get_metadata. Any stdio MCP client works the same way, including Claude Desktop, Cursor, VS Code and Windsurf.

# health, formats and configured providers
curl https://vid2context.com/api/v1/health

# transcript as text with timestamps
curl "https://vid2context.com/api/v1/transcript?url=https://youtu.be/jNQXAC9IVRw&timestamps=1"

# full context (metadata, chapters, transcript, attempts) as JSON
curl "https://vid2context.com/api/v1/context?url=https://youtu.be/jNQXAC9IVRw"

Errors return a code, a hint on how to fix them, and every attempt that was made. You can self-host the same Hono app on Node, Cloudflare Workers and other platforms.
